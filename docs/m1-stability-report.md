# M1 稳定性测试报告（T4.2）

> 对应 PRD §7-5「连续 24h 采集+录制无崩溃、无丢帧、内存无持续增长（增长 < 50MB）」，
> 以及 NFR-04（丢帧率 0 + 断电文件可校验）、NFR-05（单源故障隔离）。
> 工具：`tools/AoiTwin.Soak`（Mock 全链路浸泡，`soak <分钟> <录制目录> <报告路径>`）。
> 原始报告：`docs/_soak-raw.txt`（第一轮）、`docs/_soak2-raw.txt`（第二轮）、
> `docs/_soak-smoke.txt`（0.1.20 修正后判据输出的 3 分钟冒烟样例）。

## 1. 测试对象与判定方法

浸泡运行的是**与生产同一套**采集栈，只有传输层换成 Mock：

```
MockScenario（合成节拍：PLC 50Hz / 相机限频 / 光源打光 / 结果队列）
  └─ 四路 Mock 适配器（继承真实适配器基类：退避重连 + 健康状态机 + 异常隔离）
      └─ RealtimeHub（Topic 发布订阅）
          └─ CollectionSession → RecordingWriter（.aotrec 分帧容器：逐帧 CRC32 + 增量 SHA-256）
```

判定项由工具自动裁决，不做人工观察：

| 判据 | 工具内实现（0.1.20 起） | 阈值 |
|------|-----------|------|
| 无崩溃 | 进程存活至计划时长结束（`actualDuration` 达标） | 必须 |
| 无丢帧 | 每 500ms 采样 `Recording.DroppedFrameCount`，取全程最大值 | `maxDrops == 0` |
| 内存无持续增长 | 预热 1 分钟后取基线，全程峰值 − 基线 | `< 50MB` |
| 录制文件可校验 | 结束后 `RecordingReader.Inspect`：`IsFinalized` + `Errors` | 已终结 / 0 错误 |
| 总判定 | `memoryGrowthOk && dropsOk && inspectOk` 三项同时成立 | `result=PASS` |

内存基线刻意取**预热 1 分钟之后**的工作集，好把 JIT、反射、几何预热这类一次性开销
排除在「增长」之外——否则任何短周期测试都会把启动开销误判为泄漏。

## 2. 第一轮：15 分钟（`docs/_soak-raw.txt`）

| 项 | 值 |
|----|----|
| 计划时长 / 实际时长 | 15 分钟 / 00:15:00 |
| 录制目录 | `D:\aoi-soak`（真实磁盘，非内存盘） |
| 基线工作集 | 41 MB |
| 峰值工作集 | 55 MB |
| **峰值增长** | **13 MB** ✅（预算 50MB） |
| 采样点数 | 30（每 30s 一行） |
| 丢帧 | **全程 0** |
| 聚合速率 | 37–59 帧/秒（Mock 合成节拍，波动来自采样窗口相位） |
| 录制文件 | 14 MB |
| 校验结果 | `inspectFrames=38086`、`IsFinalized=True`、`Errors=0` |
| 判定 | **PASS** |

### 2.1 内存曲线（关键证据）

```
t=00:00  ws=37MB   ← 预热起点
t=00:01  ws=41MB   ← 基线
t=00:03  ws=45MB
t=00:05  ws=51MB
t=00:06  ws=54MB   ← 走平
t=00:07 ~ 00:14:38  ws=54MB（连续 17 个采样点完全不变）
```

**结论**：内存在第 6 分钟走平，之后 8 分钟内 17 次采样零增长。这是「有界工作集」的
典型形态——增长来自录制缓冲、字符串池、JIT 稳态开销的一次性扩张，随后进入稳态；
不存在与运行时长成正比的持续增长（泄漏的形态应是一条斜率恒定的上升直线）。

### 2.2 录制连续性

38086 帧、0 丢帧、0 校验错误，且 `IsFinalized=True`（文件尾正常收尾，非断电残件）。
按聚合速率反算：`38086 / 900s ≈ 42.3 帧/秒`，与采样速率区间一致，说明**写入侧
没有丢弃，采样侧也没漏计**。

## 3. 第二轮：20 分钟（`docs/_soak2-raw.txt`）

第二轮为**复现性交叉验证**：换录制目录（`D:\aoi-soak2`）、Release 构建、重开机后运行，
用于确认第一轮的结论不是单次偶发。

| 项 | 值 |
|----|----|
| 计划时长 / 实际时长 | 20 分钟 / 00:20:00 |
| 录制目录 | `D:\aoi-soak2` |
| 基线工作集 | 40 MB |
| 峰值工作集 | 44 MB |
| **峰值增长** | **3 MB** ✅ |
| 采样点数 | 40（每 30s 一行） |
| 丢帧 | **全程 0** |
| 聚合速率 | 34–48 帧/秒 |
| 录制文件 | 19 MB |
| 校验结果 | `inspectFrames=49693`、`IsFinalized=True`、`Errors=0` |
| 判定 | **PASS** |

内存曲线在 `t≈1min` 后即进入 42–43MB 的平台区，40 个采样点中 30 个为 42MB 或 43MB，
**20 分钟内总增长 3MB**——比第一轮更干净（第一轮峰值 55MB 出现在前 6 分钟的缓冲扩张期）。

### 3.1 两轮对比

| 指标 | 第一轮 15min | 第二轮 20min |
|------|--------------|--------------|
| 峰值增长 | 13 MB | 3 MB |
| 丢帧 | 0 | 0 |
| 校验帧数 / 错误 | 38086 / 0 | 49693 / 0 |
| 录制吞吐 | ~42 帧/秒 | ~41 帧/秒 |

两轮的帧速率与增长量级一致，说明判据可复现；差异来自首轮启动期缓冲扩张更大。

> **工具版本说明**：两轮的原始报告由 0.1.20 之前的构建产出，其头部 `recordingFile` 字段
> 是错的（把 `StartRecording()` 的 `bool` 或懒创建前的 `null` 当成路径打印）；`sample` 与
> `inspect*` 全部测量行不受影响。0.1.20 已修正为「收尾后由 `StopRecording()` 返回真实路径」，
> 并把 `result` 判定从「仅内存」加严为「内存 ∧ 零丢帧 ∧ 校验零错误」三项同时成立。

## 4. 关于 24h 全量浸泡

**本次交付未跑满 24h**，原因与替代方案如下（属计划内替代，非跳项）：

1. **阻碍**：24h 连续运行需要一台夜间独占的机器与 24h 不中断的会话窗口，本次开发
   会话不具备该条件；且演示机在办公时段被占用。
2. **替代**：以两轮不同时长的实测（15min / 20min，跨构建配置与不同录制目录）判定
   「无崩溃 / 无丢帧 / 内存有界」三项，并用**内存曲线走平的形态**替代「时长本身」作为
   泄漏判据——泄漏的时间相关性表现为斜率，而非总时长。
3. **24h 执行方式**（一条命令，无需人工值守，判据自动输出）：

```bash
dotnet run -c Release --project tools/AoiTwin.Soak -- \
  soak 1440 "D:\aoi-soak-24h" "docs/m1-stability-24h.txt"
```

该命令跑完会自行输出 `maxGrowthMB` / `maxDrops` / `inspectFrames` / `inspectErrors` / `result`，
把输出文件放进 `docs/` 即完成 §7-5 的证据归档。

**24h 才可能暴露、而短周期测不到的两个点**（如实列出，验收时重点看）：
- **文件滚动**：`MaxFileDuration=2h`，24h 会滚动 12 个文件；短周期测试不覆盖滚动边界
  的文件句柄释放与索引衔接（滚动逻辑本身已有单测 `RecordingWriterTests.Shift_roll_creates_files_with_correct_naming_and_content` 覆盖）；
- **长时间累积型泄漏**：如日志缓存、事件订阅未解绑、几何对象累积——本次以稳态曲线
  排除，但理论上仍可能以极慢速率存在（例如每班次 +1MB 量级）。

## 5. 故障与异常路径（NFR-04 / NFR-05）

浸泡之外，异常路径由自动化测试覆盖（不依赖人工造故障）：

| 场景 | 机制 | 覆盖 |
|------|------|------|
| 单数据源断线 | 适配器基类健康状态机 + 退避重连，异常在源内隔离 | `AdapterTests`、`CollectionSessionTests`：单源断线后其余通道与 UI 不受影响 |
| 采集线程饿死 | 适配器泵送改为专用长任务线程 | 回归用例（历史缺陷 0.1.12 修复） |
| 录制中途断电 | 逐帧 CRC32 + 文件尾标记；`Inspect` 扫描残件并按帧边界截断修复 | `RecordingWriterTests.Crash_without_finalize_repairable` / `Torn_tail_frame_detected_and_repaired` |
| 磁盘水位不足 | 低水位暂停录制并告警，恢复后续写 | `RecordingWriterTests.Disk_watermark_pauses_writes_and_fires_event` |
| Hub 订阅者异常 | 逐订阅者隔离，异常不外溢到发布者 | `RealtimeHubTests` |
